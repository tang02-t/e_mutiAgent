## 摘要

电力变压器是电网中最关键、最昂贵的设备之一，其故障可能引发大面积停电并造成重大经济损失。传统的变压器故障诊断高度依赖资深专家的经验，存在知识传承困难、诊断标准不统一、多源信息难以综合等问题。近年来，以大语言模型（Large Language Model, LLM）为代表的人工智能技术为故障诊断的智能化提供了新路径，但单一大模型在专业领域存在知识幻觉、推理不可控、诊断结果缺乏验证等局限。

针对上述问题，本文提出并实现了一种**基于多智能体协作的电力变压器故障诊断方法**。其核心研究思路是：将变压器故障诊断这一复杂的专家决策过程，解构为"规划—检索—生成—验证"四个职责单一的智能体，并通过图式工作流编排实现协作与质量闭环；同时融合检索增强生成（RAG）、贝叶斯网络故障归因、时序分析三类技术，构建"知识—推理—数据"三位一体的多源证据融合诊断框架。

本文已完成系统架构设计、四智能体实现、三类核心工具开发，并构建了分层可量化的验证体系。中期阶段的实验表明，故障归因引擎在标注数据上的 Top-3 命中率达 88.5%，系统工作流端到端连通率达 100%，验证了方法的可行性。本文最后分析了当前不足并给出了后续研究计划。

**关键词**：电力变压器；故障诊断；多智能体；大语言模型；检索增强生成；贝叶斯网络

## 第一章 绪论

### 1.1 研究背景与意义

电力变压器承担着电压变换与电能传输的核心功能，是电力系统安全稳定运行的枢纽。据统计，变压器故障约占电网设备故障的较大比例，且具有发展快、危害大、检修成本高的特点。因此，及时、准确地诊断变压器潜在故障，对保障电网安全、降低运维成本具有重要意义。

变压器故障诊断的核心依据包括：油中溶解气体分析（Dissolved Gas Analysis, DGA）、电气试验数据、在线监测时序信号（油温、负载、局放等）以及历史故障案例。专家通常需要综合上述多源信息，结合国家标准（如 DL/T 722-2014）和个人经验作出判断。然而，这一过程对专家经验高度依赖，存在三个突出问题：

1. **知识传承困难**：资深诊断专家稀缺，经验难以标准化、规模化传承；
2. **多源信息综合难**：DGA、时序、文献知识分属不同模态，人工综合效率低、易遗漏；
3. **诊断质量缺乏校验**：诊断结论的正确性和安全性缺乏系统化的二次验证机制。

### 1.2 国内外研究现状

**（1）传统 DGA 诊断方法**：以三比值法、Rogers 比值法、Duval 三角形为代表，基于专家规则对气体比值编码判断故障类型。这类方法可解释性强、符合行业标准，但存在"编码缺区""临界判断模糊"等问题，且无法量化故障概率。

**（2）数据驱动的智能诊断方法**：包括支持向量机（SVM）、人工神经网络（如 RBF、改进人工鱼群优化）、贝叶斯网络、故障树分析等。这类方法能从数据中学习故障模式，诊断精度较高，但普遍存在可解释性差、依赖大量标注数据、难以融合非结构化知识等不足。

**（3）大模型与智能体方法**：LLM 具备强大的语言理解与知识整合能力，配合检索增强生成（RAG）可引入领域知识。但单一 LLM 直接用于专业诊断时，存在知识幻觉、推理过程不可控、结论无验证等风险，难以满足电力行业对可靠性与安全性的严苛要求。

### 1.3 本文研究内容与思路

针对单一方法的局限，本文的**核心研究思路**是"**分而治之 + 多源融合 + 质量闭环**"：

- **分而治之**：不依赖单一大模型完成全部诊断，而是将诊断过程拆解为规划、检索、生成、验证四个子任务，由专门的智能体分别承担，降低单点复杂度、提升可控性；
- **多源融合**：将非结构化文献知识（RAG）、结构化概率推理（贝叶斯网络）、时序数据分析三类异构信息统一汇聚，模拟专家"查资料 + 算概率 + 看数据"的综合判断；
- **质量闭环**：引入独立的验证智能体对诊断结论进行结构化评估，不合格则驱动重新生成，形成自我修正机制。

本文主要研究内容包括：(1) 多智能体协作架构与图式工作流编排设计；(2) 融合三比值法与贝叶斯网络的混合故障归因方法；(3) 面向专业文献的父子分块检索增强机制；(4) 分层可量化的系统验证体系。

## 第二章 总体研究方案与系统架构

### 2.1 研究方案设计

本文采用"机理建模 + 智能体协作 + 实验验证"的研究路线。整体方案围绕一个核心命题展开：**如何让 AI 系统像资深专家一样，可靠、可解释、可验证地完成变压器故障诊断**。为此，设计了四层系统架构：用户查询层、智能体编排层、工具能力层、基础设施层。

### 2.2 多智能体协作架构

系统将诊断过程映射为四个智能体的协作流水线：

| 智能体 | 角色定位 | 核心职责 |
|--------|----------|----------|
| Planner（规划） | 诊断策略制定者 | 意图分析、任务分解、工具决策 |
| Retriever（检索） | 证据收集者 | 按计划并行调用工具，汇集多源证据 |
| Generator（生成） | 诊断结论撰写者 | 综合证据生成诊断与处理建议 |
| Validator（验证） | 质量审核者 | 结构化评估，驱动迭代返工 |

这一设计的研究动机在于：将"诊断"这一整体任务的认知负荷分散到职责单一的智能体上，每个智能体的行为更易约束与优化，且 Validator 的引入为整体输出提供了质量保障。

### 2.3 图式工作流编排与质量闭环

采用 LangGraph 的状态图（StateGraph）对智能体进行编排，工作流如下：

```
START → Planner → Retriever → Generator → Validator → [条件路由]
                                              ↑              │
                                              └──────────────┘
                                          (评估为 REVISION 时)
```

其中 Validator 的条件路由是质量闭环的核心：

| 验证判定 | 评分 | 路由 | 含义 |
|----------|------|------|------|
| PASS | ≥7 | 结束 | 诊断合格 |
| REVISION | 4–6 | 返回 Generator | 携带改进建议重新生成 |
| FAIL | <4 | 结束 | 质量不达标，输出失败提示 |

为防止无限迭代，设置最大迭代次数（默认 3）。该闭环机制使系统具备"自检—自改"能力，是本方法区别于传统单轮生成的关键。

## 第三章 关键技术要点

本章阐述本文的核心技术贡献，是中期工作的重点。

### 3.1 技术要点一：融合三比值法与贝叶斯网络的混合故障归因

**研究动机**：纯规则法（三比值法）可解释但无法量化概率，纯数据驱动法可量化但缺乏可解释性。本文将二者融合，兼取所长。

**方法设计**：构建"故障层（8 类）→ 征兆层（14 类）"的贝叶斯网络，推理分四步：

**第一步：DGA 三比值法编码**（依据 DL/T 722-2014 表6）

| 特征比值 | 编码规则 |
|----------|----------|
| C₂H₂/C₂H₄ | <0.1→0；[0.1,3)→1；≥3→2 |
| CH₄/H₂ | <0.1→1；[0.1,1)→0；≥1→2 |
| C₂H₄/C₂H₆ | <1→0；[1,3)→1；≥3→2 |

**第二步：朴素贝叶斯后验推理**。给定观测征兆集合 $E$，计算各故障 $F_i$ 的后验概率：

\[
P(F_i \mid E) \propto P(F_i) \cdot \prod_{e_j \in E} P(e_j \mid F_i)
\]

其中先验 $P(F_i)$ 与条件概率 $P(e_j \mid F_i)$ 依据领域知识标定，并归一化。

**第三步：规则—概率融合**。当三比值法匹配到故障规则时，对贝叶斯结果加权修正：

\[
P_{\text{fused}}(F_i) = 0.7 \cdot P_{\text{bayes}}(F_i) + 0.3 \cdot P_{\text{rule}}(F_i)
\]

**第四步：排序与分级**，输出故障概率排序、严重程度（高/中/低风险）及 DGA 特征解释。

**技术价值**：该方法既输出符合国标的可解释判据，又给出量化的故障概率排序，弥补了单一方法的不足。

### 3.2 技术要点二：父子分块的检索增强机制

**研究动机**：变压器专业文献篇幅长、含大量图表。检索分块过细则上下文不完整，过粗则检索噪声大。

**方法设计**：采用父子分块（Parent-Child Chunking）策略：

```
① 向量检索仅在细粒度"子块"上进行（保证命中精度）
② 通过 parent_id 展开对应"父块"完整章节（保证上下文完整）
③ 返回"子块（精确命中）+ 父块（完整上下文）"组合
```

基于 Milvus 向量库与 text-embedding-v4 嵌入模型实现，并原生支持图文混排。该机制同时解决了检索精度与上下文完整性的矛盾。

### 3.3 技术要点三：多源异构证据的统一融合

**研究动机**：模拟专家综合判断，需统一管理多模态证据。

**方法设计**：通过共享状态对象 `AgentState` 与工具结果格式化层，将三类异构信息汇聚：

- **非结构化知识**：RAG 检索的文献片段；
- **结构化推理**：贝叶斯网络的故障概率排序；
- **时序数据**：油温预测（线性回归 + 滚动预测）与 3σ 异常检测结果。

Generator 智能体综合上述证据生成诊断，使系统判断更贴近真实运维场景。

### 3.4 技术要点四：全链路降级的工程鲁棒性设计

**研究动机**：实际部署中外部依赖（LLM API、向量库）可能失效，系统须保证可用性。

**方法设计**：在每个环节设计降级路径——工作流（图式→串行）、智能体（LLM→模板/规则）、规划（空计划→固定工具集）、检索（向量库→本地）。任一依赖失效时系统仍可降级运行，保障鲁棒性。

## 第四章 实验验证

### 4.1 验证体系设计

为科学评价方法效果，本文设计了**两层验证体系**，分别考核确定性归因能力与端到端系统能力。

### 4.2 数据集构建

由于真实标注的变压器故障数据获取受限，本文按标准 schema 构建了自洽的模拟数据集用于方法验证，并已调研了可替换的公开真实数据集（如 Kaggle Power Transformers FDD、IEEE DataPort DGA dataset、ETDataset 等）：

| 数据集 | 规模 | 用途 |
|--------|------|------|
| DGA 油色谱（含故障标签） | 3000 条 | 归因引擎评测 |
| 在线监测时序 | 20 台 × 2000 点 | 时序预测评测 |
| 故障案例库 | 200 例 | 知识增强 |
| 端到端评测集 | 120 条 | 系统评测 |

数据按三比值法编码区间生成，保证物理自洽性。

### 4.3 故障归因引擎评测

采用 Top-1 准确率、Top-3 命中率、各类 F1、分严重程度召回率等指标。当前基线结果：

| 指标 | 数值 |
|------|------|
| Top-1 准确率 | 37.9% |
| Top-3 命中率 | 88.5% |
| critical（高危）故障召回率 | 100% |
| serious 故障召回率 | 32% |

**结果分析**：Top-3 命中率达 88.5%，说明数据特征与故障强相关、归因引擎能将真实故障排进前三；高危（critical）故障召回率达 100%，满足安全底线要求。Top-1 偏低的原因在于贝叶斯网络的条件概率表当前为人工标定的近似值，似然连乘对高产气故障存在偏倚——**这一发现明确了下一阶段需用真实数据校准条件概率表的研究方向**。

### 4.4 端到端系统评测

采用流程完成率、主故障命中率、关键要点覆盖率、安全合规率、迭代轮次等指标。实验表明系统工作流**端到端连通率达 100%**，验证了多智能体编排与降级机制的有效性。当前受 LLM 接口配额限制，真实诊断能力的完整评测将在后续阶段补充。

1. 完成多智能体协作架构设计与 LangGraph 图式工作流编排，实现质量验证闭环；

3. 端到端真实诊断能力评测受 LLM 配额限制，尚未完整开展。
